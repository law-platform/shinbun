# 法律新聞

『法律新聞』第 1 号〜第 92 号（明治 33 年 9 月 24 日〜明治 35 年 6 月 23 日）と号外 1 号の本文を、記事ごとに全文検索して読む静的サイト。
検索の動き（号での絞り込み、該当箇所の文脈表示、各号のページでの検索語の強調）と索引の形式は、司法省日誌（https://shiho-nisshi.github.io/ ）と同じ。
ただし入力しながらは検索せず、Enter か検索ボタンで検索する。

テキストデータは、明治大学社会・人間・情報プラットフォームプロジェクト（SHIP プロジェクト）における研究成果物の一部です。

## 構成

```
index.html            全文検索（号の一覧は出さず、号を選んで開くプルダウンだけを置く。検索中は隠す）
docs/<号>.html        各号の本文（0001.html … 0092.html、号外は gogai-<発行日>.html）。記事ごとのカードで、id は TEI の xml:id
style.css             見た目（明治法律辞書検索 juridic・明治法典編纂議事録 arthis と共通の作り）
fulltext/             全文検索
  fulltext.js           検索欄と結果の表示、各号のページでの検索語の強調（司法省日誌のものと同じ）
  meta.json             号の一覧（号の名前と最初の記事の番号）、旧字→新字の対応表、索引を分けたファイルの数
  b/N.json              索引（正規化した本文の隣り合う 2 文字 → それを含む記事と出現位置）。検索語に必要なファイルだけ読み込む
  u/N.json              索引（1 文字 → それを含む記事）
  t/N.json              記事の見出し・種類・本文。表示する記事の分だけ読み込み、該当箇所と前後の文脈を出す
```

## 検索の書き方

- 空白で区切ると、すべての語を含む記事を探す（AND）。
- 旧字・新字（權／権）、ひらがな・カタカナ、全角・半角、改行の違いは区別しない。
  旧字→新字は、法律情報基盤の共通の対応表 `kanji_normalize.tsv` による。
- 検索結果は記事ごと。号で絞り込める。結果の見出しから、その号のページの該当記事へ移り、検索語が強調される。

## データの更新

このフォルダの中身はすべて、このリポジトリの外にある変換プログラム
`shinbun/program/convert_shinbun_to_html.ps1`（索引の作成は `shinbun/program/shinbun_search.cs`）が、
元データ `shinbun/data/*.xml`（TEI、1 号 1 ファイル）から生成する。

元データを変えたら、`shinbun/` 直下で:

```
powershell -File program\convert_shinbun_to_html.ps1
```
